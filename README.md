# Void Dominion TTS Assets

Public Tabletop Simulator asset host for Void Dominion.

This folder should contain only generated PNG assets from the private Void Dominion prototype folder.

Use GitHub Pages with:
- Source: Deploy from a branch
- Branch: main
- Folder: /root

Example hosted URL after publishing:

```text
https://YOUR_USERNAME.github.io/void-dominion-tts-assets/boards/map_board.png
```
